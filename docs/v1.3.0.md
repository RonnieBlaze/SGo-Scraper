# v1.3.0 — Colored output

**Date:** 2026-10-31
**Previous:** [v1.2.0](v1.2.0.md)
**Status:** Superseded by [v1.3.1](v1.3.1.md). It builds, passes `go vet` and all 14 unit tests, and turns color off when output is redirected. Live-tested on 2026-10-31 through `StartWatcher.bat` in the Windows console: every color showed correctly (headings, counters, skips, retry, progress bars).

This release adds color to the console output, so you can tell at a glance what's downloading, what was skipped, and what went wrong.

## Added

| Color | Used for |
|-------|----------|
| Cyan, bold | Section headings (`Found 12 Photosets`, `Found 3 Videos`, …) and the model name |
| White, bold | The item being downloaded (`Found "Sunny Day" set…`, `Candid post…`, `Video post…`, `Group thread…`) and the URL |
| Blue | `[03/40]` item counters |
| Cyan → green | The progress bar: cyan while downloading, green when complete. The MB total is grey |
| Green | `Logged in as …`, `Saved <video> (N MB)`, `<Model> Finished Downloading...` |
| Yellow | `[retry …]` lines and warnings (unknown title format, missing album date) |
| Red | `Error: …` lines, `Failed: …` lines, video failures, the end-of-run failure list; bold red for a 429 |
| Grey | `[skip] …` lines, `AlbumDir` / `PostDir` / `ModelDir` / `VideoDir` / `ThreadDir` paths, `[group] …` details, the run timestamp, and posts with no images |

**New line:** a finished video now prints `Saved <file> (N MB)` in green, since videos have no progress bar.

## How it works

- `color.go` has one helper per meaning (`errorText`, `warnText`, `okText`, `headingText`, `itemText`, `dimText`, `indexText`), so a color is changed in one place.
- On Windows, `color_windows.go` turns on the console's ANSI support (`ENABLE_VIRTUAL_TERMINAL_PROCESSING`). This is needed in the classic console window that `StartWatcher.bat` opens. `color_other.go` handles other systems.
- Color is off when:
  - stdout isn't a console (for example, redirected to a log file)
  - `NO_COLOR` is set
  - `COLOR=off` is in `.env`

## Changed

- `golang.org/x/sys` is now a direct dependency (it was already indirect).
- `formatIndex` returns the counter colored, with no change to its text.
- Text is unchanged everywhere else. Only colors were added, apart from the new `Saved …` line for videos.

## New settings (`.env`, optional)

| Setting | Default | Purpose |
|---------|---------|---------|
| `COLOR` | on | `off` gives plain output |
